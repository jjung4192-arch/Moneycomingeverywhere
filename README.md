# Orbit
인스타그램 계정·콘셉트·독자·수익화 목표를 입력해 주간 운영 계획을 만드는 한국어 프로토타입입니다. 주식·ETF 콘셉트의 교육 콘텐츠 템플릿을 제공합니다.

## 실행
Node.js 22 이상에서 외부 패키지 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. `npm test`로 HTTP 스모크 테스트를 실행합니다.

## 현재 지원
계정별 운영 설계, 주 3/5회 콘텐츠 템플릿, 초안 검토 상태, 브라우저 로컬 저장, JSON 내보내기. 사용자 입력은 텍스트로 렌더링합니다. 서버에는 입력 내용이 전송되지 않습니다.

## 실제 운영 서비스로 확장하기 위한 작업
현재는 규칙 기반 계획 도구입니다. AI 생성·Meta OAuth·게시·지표 수집·결제 기능은 구현되지 않았습니다. 입력한 계정명은 소유권 인증이 아닙니다. 검토 버튼은 게시를 실행하지 않습니다. 로컬 저장은 기기 간 공유되지 않습니다.

실제 서비스에는 사용자 인증, 데이터베이스, 암호화된 OAuth 토큰 저장, 지원되는 Instagram 프로 계정과 Meta 앱 권한/심사, 공식 발행 API, 실패 재시도를 포함한 작업 큐, AI 제공자, 사실 확인·승인 과정, 지표 수집 및 상품/결제 연결이 필요합니다. 비밀번호를 수집하지 마세요. 권한은 Meta의 현재 공식 문서에 따라 확인하세요. 수익을 보장하지 않으며 협찬·제휴 표기를 지원해야 합니다. 투자 콘텐츠의 출처와 기준일은 사람이 검증해야 합니다.

## 서비스 모델
콘텐츠 운영 SaaS 구독 + 선택형 제작 서비스. 계정 소유자의 수익화 경로는 교육 자료 판매, 협찬, 공개된 제휴 프로그램입니다. 실제 지표와 판매 데이터가 연결되기 전에는 매출 추정치를 실적으로 표시하지 않습니다.
