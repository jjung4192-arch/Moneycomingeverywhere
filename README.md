# Orbit
인스타그램 프로필 링크 하나를 입력하는 한국어 테스트 사이트.

## 실행
Node.js 22 이상에서 `npm start`. 외부 패키지 설치는 필요 없습니다. 포트는 기본 3000이며 `PORT`로 변경할 수 있습니다. `npm test`는 URL 검증과 HTTP 스모크 테스트를 실행합니다.

## 공개
GitHub Pages의 main 브랜치 /docs 폴더. public이 원본이며 변경 시 docs에 동일한 파일을 복사합니다.

## 현재 기능과 한계
프로필 링크의 도메인·사용자명 검증과 정규화, 계정 표시, 프로필 이동. 사용자 데이터는 서버에 전송하거나 저장하지 않습니다. 계정 분석과 자동 운영은 미구현이며 화면에 연결 필요 상태로 명시합니다. 팔로워 수·반응률 등 가상 수치를 표시하지 않습니다. 기존 로컬 운영 계획은 삭제하지 않지만 새 화면에서 사용하지 않습니다.

실제 기능에는 Meta 공식 OAuth, 지원되는 계정의 소유권 확인 및 앱 권한/심사, 서버와 데이터베이스, 안전한 토큰 보관, 게시물·인사이트 수집, 콘텐츠 제작·승인·예약 작업 큐가 필요합니다. 프로필 URL만으로 계정 접근 권한을 얻을 수 없습니다. 비밀번호를 수집하지 마세요. 수익이나 성장을 보장하지 않습니다.
