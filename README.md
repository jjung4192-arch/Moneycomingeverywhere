# PhotoBridge — 아이폰 사진을 Windows PC로
Windows 10/11 x64용 초기 시험 앱입니다. USB로 연결한 iPhone에서 새 사진·동영상을 선택한 폴더로 가져옵니다. 아이폰 앱 설치나 서버 업로드가 없습니다. **실제 iPhone/Windows USB 동작은 아직 검증되지 않았습니다.**

## 사용
GitHub 저장소 Releases에서 최신 PhotoBridge 시험판의 `PhotoBridge-Windows-x64.zip`을 다운로드·압축 해제 후 `PhotoBridge.exe`를 실행합니다. 빌드·배포가 성공하기 전에는 다운로드 파일이 없습니다. Actions → Build Windows app의 실행 결과에서도 빌드 상태와 아티팩트를 확인할 수 있습니다. .NET 런타임은 포함되며 관리자 권한은 요구하지 않습니다. 코드 서명되지 않은 시험 빌드이므로 Windows가 경고하거나 실행을 제한할 수 있습니다. 보안 기능을 끄지 마세요.

1. 데이터 전송용 USB 케이블로 아이폰을 연결하고 잠금을 풉니다.
2. 아이폰의 ‘이 컴퓨터를 신뢰’와 사진 접근 요청을 승인합니다.
3. Windows 탐색기 ‘내 PC’에 iPhone과 사진 폴더가 표시되는지 확인합니다. 인식되지 않으면 Apple 공식 기기 지원 소프트웨어/드라이버와 케이블부터 확인하세요.
4. 앱에서 저장 폴더를 선택하고 ‘새 사진 가져오기’를 누릅니다.
5. 완료·건너뜀·실패 수와 오류를 확인합니다. iPhone 원본을 삭제하는 기능은 없습니다.

## 현재 범위
Windows Shell COM의 사진 폴더를 순회해 JPG/HEIC/PNG/DNG/MOV/MP4 등과 AAE를 복사합니다. 라이브 포토 구성 파일은 각각 가져오며, 사진 앱의 앨범·편집 상태로 재구성하지 않습니다. HEIC를 JPG로 변환하지 않습니다. 사진 보기에는 PC의 코덱이 필요할 수 있습니다.

완료 파일은 크기를 확인하고 PC 복사본 SHA-256을 기록합니다. 이후 실행에서 기록된 PC 파일의 해시까지 확인해 건너뜁니다. iPhone 원본 해시를 읽지 않으므로 원본과의 바이트 단위 일치 검증이 아닙니다. 원본 경로·크기·수정 시각으로 식별하므로 재연결/기기 업데이트에 따른 경로 변화나 같은 메타데이터의 원본 변경에는 제한이 있습니다.

저장 폴더의 `.photo-bridge/manifest.json`에 완료 기록을 보관합니다. 같은 파일명은 덮어쓰지 않습니다. 중단 후 다시 실행하면 **완료된 파일 단위**로 이어받습니다. 대용량 파일 내부에서 바이트 단위 이어받기는 지원하지 않습니다. 복사 중단 후 Windows Shell 작업이 잠시 계속될 수 있어 임시 파일은 남을 수 있습니다. 아이폰 원본은 변경하지 않습니다. 기록 파일이 손상되면 작업을 중단하며 조용히 기록을 초기화하지 않습니다.

iCloud 최적화로 기기에 원본이 없으면 먼저 아이폰에서 다운로드해야 할 수 있습니다. 잠금·케이블 해제·드라이버 상태에 따라 오류가 날 수 있습니다. 파일당 10분 제한이 있으며 아주 큰 영상은 실패할 수 있습니다. 여러 아이폰 동시 가져오기는 지원하지 않습니다. 네트워크로 사진을 보내거나 계정을 수집하지 않습니다.

## 개발
.NET 8 SDK. `dotnet run --project tests/PhotoBridge.Checks`로 플랫폼 공통 복사 검증. Windows UI: `dotnet run --project src/PhotoBridge.Windows`. Linux에서는 Windows 타깃 빌드는 가능하지만 UI/USB 실행은 불가능합니다. GitHub Actions가 Windows x64 독립 실행 빌드를 생성합니다.
