다운로드 페이지에서 ZIP 파일을 받으세요.
첫 빌드 중이거나 실패했다면 파일이 아직 없을 수 있습니다.
빌드 파일과 진행 상태 확인

  1. 아이폰을 연결하고 잠금·신뢰 요청을 확인합니다.
  2. ZIP을 풀고 PhotoBridge.exe를 실행합니다.
  3. 저장 폴더를 선택한 뒤 새 사진 가져오기를 누릅니다.
실제 iPhone USB 전송 시험 전 버전입니다. 이 웹페이지는 사진을 옮기지 않으며 Windows 앱을 별도로 실행해야 합니다. 먼저 적은 수의 사진으로 시험하세요. 서명되지 않은 앱이 차단되면 보안 기능을 끄지 마세요.
